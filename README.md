# GitHub Enterprise Server releases

Review information for each version of GitHub Enterprise Server: closing down dates, links to documentation, and minimum recommended versions of supporting applications.

GitHub Enterprise Server is constantly improving, with new functionality and bug fixes introduced through feature and patch releases. See [About upgrades to new releases](/en/enterprise-server@3.22/admin/overview/about-upgrades-to-new-releases).

GitHub supports at least the **four** most recent feature releases.

We provide documentation for both supported and unsupported versions of GitHub Enterprise Server. We do not maintain or update the documentation for unsupported versions.

For information about the latest release, see the [GitHub Enterprise](https://github.com/enterprise) website.
